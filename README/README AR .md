# محطة FN

عميل سطح مكتب لنظام ويندوز لـ Feiniu NAS، تم تطويره باستخدام PySide6 + QtWebEngine.

## الميزات

- **البحث الذكي لـ FN Connect** — أدخل معرف FN لإرسال طلبات متوازية إلى `5ddd.com` و `fnos.net`. إذا كان الموقعان متاحين، يتيح للمستخدم الاختيار، وإذا كان واحدًا فقط متاحًا يتم الاتصال مباشرة.
- **التكيف مع العناوين** — يدعم معرف FN (`mynas`)، اسم النطاق الكامل (`mynas.5ddd.com`) وعنوان IP للشبكة المحلية (`192.168.1.100:5666`).
- **تخزين بيانات الاعتماد المشفرة** — ثلاثة أوضاع مع تراجع تلقائي.
- **قفل بصمة الشهادة** — يعرض بصمة SHA‑256 عند أول اتصال ويحفظها بعد موافقة المستخدم، ويظهر تحذير في حال تغير البصمة.
- **ملء الحساب وكلمة المرور تلقائيًا** — بعد تحميل الصفحة، يحاكي إدخال لوحة المفاتيح من خلال أحداث Qt دون استخدام لوحة مفاتيح النظام.
- **واجهة داكنة** — نافذة بدون حدود، شريط عنوان مخصص، سمة لون Feiniu الأخضر.
- **بنية نافذة واحدة** — روابط النوافذ الجديدة في صفحات الويب يتم تحميلها في نفس المكان.

## التشغيل

### بايثون

قم بتنزيل المستودع ثم قم بتشغيل:

```
python main.py
```

### الإصدار المحمول وملف التثبيت

قم بالتنزيل من صفحة Release.

## الاستخدام

1. قم بتشغيل البرنامج.
2. أدخل معرف FN أو عنوان جهاز NAS.
3. اختياري: أدخل اسم المستخدم وكلمة المرور ثم حدد «تذكر كلمة المرور».
4. انقر على «اتصال».

عند الاتصال لأول مرة بجهاز NAS يستخدم شهادة موقعة ذاتيًا، ستظهر نافذة حوار بتفاصيل الشهادة. تحقق من التفاصيل ثم انقر على «متابعة على أي حال».

إذا تم تفعيل المصادقة الثنائية (2FA) على حساب Feiniu، سيقوم البرنامج بملء الحساب وكلمة المرور تلقائيًا، ويجب إدخال رمز التحقق يدوياً.

## ملاحظات الأمان

### موقع تخزين بيانات الاعتماد

```
%USERPROFILE%\.fnos-browser\data.json
```

بنية الملف:

```json
{
  "url": "عنوان IP لـ Feiniu أو معرف FN",
  "render_mode": "auto",
  "trusted_certs": { },
  "secure_blob": {
    "mode": "tpm",
    "data": "بيانات مشفرة بترميز base64"
  }
}
```

فقط حقل `secure_blob` مشفر، أما باقي الحقول فهي بنص عادي.

### ثلاثة أوضاع للتشفير

| الوضع                 | شرط التنشيط                                      | تجربة المستخدم        | مستوى الأمان                      |
| --------------------- | ------------------------------------------------ | --------------------- | --------------------------------- |
| تشفير الأجهزة TPM 2.0 | اللوحة الأم مزودة بشريحة TPM                     | شفاف، فك تشفير تلقائي | أعلى، المفاتيح لا تخرج من الشريحة |
| تشفير بصمة الجهاز     | لا توجد شريحة TPM والحساب لا يحتوي على كلمة مرور | شفاف                  | متوسط، المفاتيح مرتبطة بالأجهزة   |

جميع البيانات المشفرة مرتبطة بالجهاز الحالي ولا يمكن فك تشفيرها عند نسخها إلى جهاز كمبيوتر آخر.

### قفل بصمة الشهادة

لا يثق البرنامج بجميع الشهادات بشكل أعمى. عند أول اتصال يتم عرض بصمة SHA‑256 للشهادة والجهة المصدرة وفترة الصلاحية، وتُكتب هذه البيانات في ملف `data.json` بعد موافقة المستخدم. في الاتصالات اللاحقة تتم المقارنة تلقائيًا:

- تطابق البصمة → السماح بالوصول مباشرة
- تغير البصمة → ظهور تحذير باللون الأحمر

### ترحيل النسخ الاحتياطي لكلمات المرور

استخدم القائمة «🔐 ترحيل كلمات المرور» للتبديل بين طرق التشفير المختلفة.
استخدم القائمة «📤 تصدير بيانات الاعتماد» لتصدير بيانات الاعتماد إلى ملف مشفر بامتداد `.fnosbak`، ثم استعِدها على جهاز آخر من خلال «📥 استيراد بيانات الاعتماد».

## بنية المشروع

```
├── main.py                  # نقطة دخول البرنامج
├── config.py                # أنماط QSS العامة
├── data_store.py            # إدارة البيانات الموحدة
├── secure_store.py          # تشفير بيانات الاعتماد
├── trust_store.py           # تخزين بصمات الشهادات
├── cert_dialog.py           # نافذة حوار الثقة بالشهادة
├── password_dialog.py       # نافذة حوار إدخال كلمة المرور
├── migrate_dialog.py        # ترحيل وتصدير واستيراد كلمات المرور
├── search_dialog.py         # تحديد نتائج بحث FN Connect المتعددة
├── settings_dialog.py       # إعدادات وضع العرض
├── fn_connect.py            # البحث في نطاقي FN Connect
├── custom_page.py           # WebEnginePage مخصص
├── title_bar.py             # شريط عنوان مرسوم يدوياً
├── browser.py               # منطق النافذة الرئيسية
├── keyboard_sim.py          # محاكاة لوحة المفاتيح بأحداث Qt
├── inject.js                # نص برمجي يتم حقنه في الصفحات
├── installer.iss            # نص برمجي تعبئة Inno Setup
└── pages/
    ├── __init__.py
    ├── welcome.py           # صفحة الترحيب
    ├── loading.py           # قيد التحميل
    └── error.py             # صفحة الأخطاء
```
