关于飞牛终端

-

飞牛终端（fn-desktop-plus）的 NAS 服务端管理后台，负责账号权限、文件读写、分享外链与 Docker 容器编排。

  • 通信协议TLS 1.3 · 自签证书
  • 数据存储SQLite（WAL）+ AES-256-GCM
  • 密码算法Argon2id
  • 客户端Qt 6 桌面端 / 浏览器

存储挂载

加载中…

把 NAS 上的绝对路径挂载到文件管理的 /m/<名称> 下，文件实体不会移动。 首次使用请先到飞牛「设置 → 应用 → 飞牛终端 → 文件夹权限」授予目标目录的读写权限， 否则挂载会因无权限失败（可先勾选「只读挂载」）。

正在加载挂载点…

自动挂载会扫描 /vol1 下所有可读的非系统目录并逐个挂载；没有出现任何目录说明应用还没有拿到文件夹权限。
